Zuck — the meta model manager

Zuck plans with Meta models: Spark for text at light, standard, or deep effort, Wonder for the hardest planning and review, Image for pictures, SAM 3.1 for vision, and you for the calls only a human makes. Gates hold: a task never starts until the work it depends on is done. Independent tasks run together. Code on GitHub.
